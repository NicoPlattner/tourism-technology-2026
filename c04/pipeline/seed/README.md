Derived model outputs (aggregates, no raw data) used by `models/refresh.py` when the TTF Data Space data
cannot be fetched: lead time by arrival month and market (from TVB Paznaun-Ischgl booking data), age profiles
(from Salzburger Sportwelt guest cards), Paznaun origin x month. Licences allow distributing derived results
with attribution: TVB Paznaun-Ischgl with feratel; Salzburger Sportwelt (TTF 2026 data licences).
